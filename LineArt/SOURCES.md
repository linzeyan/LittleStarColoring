# Line art sources

Every page is generated locally with **Z-Image-Turbo, 8-bit MLX quantization**
(`AbstractFramework/z-image-turbo-8bit`, a derivative of Tongyi-MAI/Z-Image-Turbo).
A picked page with a small flaw is fixed with **Qwen-Image-Edit-2511, 8-bit MLX
quantization** (`AbstractFramework/qwen-image-edit-2511-8bit`). A page whose model
column says `bf16` was generated with **Z-Image-Turbo in bf16** instead
(`mlx-community/Z-Image-Turbo-bf16`, the same model unquantized). License of all three:
**Apache 2.0**, stated in each model card and its LICENSE.md. Generated: 2026-10-17;
the fish redrawn 2026-10-22; 57 pages (every `bf16` row but the fish) redrawn 2026-10-23.

## How each page is made
`tools/generate_pages.py` reads this file: the style lines below and the table.
```
uv run tools/generate_pages.py generate   # seeds 1–3 per page → LineArt/candidates/
uv run tools/generate_pages.py review     # candidates through the page pipeline, as sheets
uv run tools/generate_pages.py edit       # Qwen-Image-Edit on the picked seed, per the edit column
uv run tools/generate_pages.py pick       # the picked seed (or its edit) → LineArt/sources/
```
Generation: `--steps 8 --guidance 0 --width 1024 --height 1024`, prompt = style + subject.
An edit is one Qwen pass, or several joined by ` → ` that run in turn, each on the result
of the one before; `[N] ` before a pass sets its seed (default 1).
Styles, one per category; a style line starts with the categories it styles, and a
page's prompt is its category's style + its subject. A line led by single pages
(`category/page`) styles just those, over their category's: how a category is drawn
can't change without breaking the pages that reproduce from it. A style says how to draw, never
what: an object or part it names (tyres, the sun, horns) turns up on every page it styles.

A seed is rejected if it has:
- fewer than 2 colorable regions;
- regions too small for a finger;
- an outline leak;
- a person or rider in the picture;
- a face on a vehicle, plant, fruit, food or sky page;
- a solid black fill;
- a look-alike of a known character;
- a shape that doesn't read as its subject;
- an odd body: extra or missing legs, a limb bent the wrong way.

The copy in `LineArt/sources/` is converted to grayscale, which the page pipeline reads anyway.
